# 1.5.0 更新内容

## 应用更名与全新图标

- 应用更名为「AI小说搭子」（英文名 AINovelBuddy），并换上全新的橙色羽毛笔应用图标。
- 原名「书童」。作品、设置与安装位置都不变，直接安装即可升级；桌面和开始菜单快捷方式会更新为「AI小说搭子 AINovelBuddy」。任务栏固定的旧图标升级后需要重新固定一次。

## 移除内置自动更新

- 本版本起移除应用内自动更新功能。新版本将在 GitHub Releases 页面发布，请从发布页手动下载安装包覆盖安装。

## 其他

- Windows 与 macOS 安装包仍为未签名构建（安装时系统会提示未知发布者/未公证，与 1.4.0 相同）。

# 1.5.0 Release Notes (English)

## New name and icon

- The app is renamed to 「AI小说搭子」 (AINovelBuddy) with a brand-new app icon: an orange quill over manuscript lines.
- Formerly "书童" (Pagekin). Books, settings, and the install location are unchanged — install over the top to upgrade. Desktop and Start-menu shortcuts update to "AI小说搭子 AINovelBuddy"; taskbar pins need re-pinning once after the upgrade.

## In-app auto-update removed

- The in-app updater is removed in this version. New versions are published on the GitHub Releases page — download and run the installer manually.

## Other

- Windows and macOS installers remain unsigned (the OS may warn about an unknown publisher / not-notarized builds, same as 1.4.0).
